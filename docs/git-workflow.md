# Git Workflow

## 1. Check Status

git status

## 2. Stage Changes

git add .

## 3. Commit Changes

git commit -m "Add project files"

## 4. Push Changes

git push origin main

## 5. Create Branch

git branch feature-branch

## 6. Switch Branch

git switch feature-branch

## 7. Merge Branch

git switch main
git merge feature-branch
