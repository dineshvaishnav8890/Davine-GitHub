# Git Workflow

## 1. Check Status

git status

## 2. Stage Changes

git add .

## 3. Commit Changes

git commit -m "Add project files"

## 4. Push Changes

git push origin main

## 5. Create Branch

git branch feature-branch

## 6. Switch Branch

git switch feature-branch

## 7. Merge Branch

git switch main
git merge feature-branch

## Branching Best Practices

1. Create a separate branch for every feature.
2. Use meaningful branch names.
3. Test changes before merging.
4. Keep the main branch stable.
5. Delete completed feature branches when appropriate.

## Rebase Practice

Git rebase moves feature branch commits onto the latest base branch.
It helps maintain a linear project history.
